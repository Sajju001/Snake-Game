🐍 Snake Game

A modern, smooth, and fully playable Snake Game built for the web with a unique futuristic gaming interface.

The project combines classic Snake gameplay with a professional UI, responsive controls, animations, sound effects, difficulty levels, and browser-based game history.

✨ Features
🎮 Fully playable Snake game
🐍 Smooth snake movement
🍎 Dynamic food system
🏆 High score tracking
📊 Game statistics
📜 Game history
💾 Persistent browser storage using LocalStorage
⚡ Progressive difficulty and level system
🎚️ Easy, Medium & Hard difficulty
⏸️ Pause / Resume system
🔊 Sound effects with ON/OFF control
📱 Fully responsive design
👆 Mobile touch controls
⌨️ Arrow Keys & WASD support
🎨 Modern futuristic gaming UI
✨ Neon/glow visual effects
🌟 Level-up and high-score animations
⚙️ Customizable settings
🚫 No backend required
🎮 Controls
Desktop
Control	Action
↑ ↓ ← →	Move Snake
W A S D	Move Snake
Space	Pause / Resume
Esc	Return to Menu
Mobile

Use the on-screen directional controls or swipe gestures to control the snake.

💾 Game Data

Game data is stored locally in the user's browser using LocalStorage.

Stored information includes:

High Score
Previous Scores
Total Games
Total Points
Best Level
Longest Snake
Difficulty
Sound Preferences
Game Settings
Last Played Information

No account or backend database is required.

🕹️ Gameplay

The objective is simple:

Control the snake.
Eat food to increase your score.
Each food item makes the snake longer.
Avoid hitting the walls.
Avoid hitting your own body.
As your score increases, the game becomes faster.
Try to achieve a new high score.
🎯 Difficulty Modes
Easy

Slower gameplay designed for beginners.

Medium

Balanced gameplay and the default difficulty.

Hard

Faster movement for players looking for a challenge.

🚀 Getting Started

Clone the repository:

git clone https://github.com/Sajju001/Snake-Game.git

Open the project folder:

cd snake-game

Then open index.html in your browser.

No installation or backend setup is required.
